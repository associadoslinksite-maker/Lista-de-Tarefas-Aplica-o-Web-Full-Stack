# ✅ Lista de Tarefas — Full Stack

Aplicação web simples e funcional para organização de tarefas, desenvolvida com Python e Flask.

## 🛠️ Tecnologias
- **Python + Flask** — Back-end
- **SQLite** — Banco de dados
- **HTML5 + Bootstrap** — Front-end responsivo

## ✅ Funcionalidades
- ✅ Adicionar novas tarefas
- ✅ Marcar/desmarcar como concluída
- ✅ Excluir tarefas
- ✅ Salva automaticamente no banco de dados
- ✅ Interface responsiva — funciona no celular
- ✅ Confirmação antes de excluir

## 🚀 Como rodar
```bash
pip install flask
python app.py
