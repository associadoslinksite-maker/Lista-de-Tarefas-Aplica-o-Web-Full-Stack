# Lista-de-Tarefas-Aplica-o-Web-Full-Stack
Aplicativo completo de gerenciamento de tarefas com armazenamento em banco de dados SQLite. Permite adicionar, concluir e excluir tarefas de forma simples e intuitiva. Interface responsiva construída com Bootstrap.   ✅ Tecnologias: Python | Flask | SQLite | HTML5 | Bootstrap ✅ CRUD completo ✅ Persistência de dados ✅ Design adaptável a celular
